# BC
> 一款 Android 原生健身训练记录应用：力量 + 有氧、训练计划与周期排课、组间休息计时器、训练日历与数据统计，数据本地优先并支持 JSON 备份。

## 项目简介
BC（BrawnCatalog）是一款独立开发的安卓健身记录工具，目标是做一套轻量、本地优先的健身日志 App。
它记录每一次训练的重量、组数、次数、RPE 与组间休息，覆盖力量训练和有氧训练两套体系；并围绕训练闭环提供自定义训练计划与周期排课、组间休息倒计时、训练日历热力图、多维度统计图表、身体数据趋势以及 JSON 导入导出备份。
整个项目使用 Kotlin 原生开发，无后端服务，训练数据默认保存在本机，不联网上传。

## 核心功能
### 力量训练模块
- 训练部位管理：胸、肩、背、腿、手臂、核心等部位入口，支持二级分类
- 动作库：内置动作数据集，动作详情支持离线 GIF 动图演示，也可自定义新增动作
- 双颗粒度录入：快速模式（重量 / 组数 / 次数）与专业模式（训练体重、RPE、组间休息）
- 动作历史与 PR：查看单个动作的历史记录和重量进步，刷新个人纪录时给出庆祝提示

### 有氧训练模块
- 内置常见有氧动作：慢跑、快走、跳绳、骑行、游泳、爬楼等
- 记录时长与备注

### 训练计划模块
- 多计划管理：划分训练日与休息日，按天配置动作和组次
- 动作选择器：从动作库快速挑选动作并编排到训练日
- 周期排课：按周期把计划排入训练日历，自动生成训练日与休息日

### 组间休息计时器
- 训练中一键开始倒计时，支持常用时长快捷设置
- 前台服务保活，息屏或切后台继续计时，结束时通知 + 震动提醒
- 精确闹钟兜底，进程被清理也能按时提醒

### 训练日历与统计
- 训练日历：GitHub 风格热力图展示训练频率，点选日期查看当日训练
- 月度训练次数、动作重量趋势、月度柱状对比与饼图分布
- 肌肉部位平衡与训练覆盖率分析

### 身体数据
- 记录体重、体脂、肌肉量、腰围
- 体重趋势折线图，支持近一周 / 近一月 / 近一年

### 备份与恢复
- JSON 格式导出全部训练数据
- JSON 文件导入恢复数据
- 使用 SAF 存储访问框架，不需要申请存储权限

### 体验优化
- 7 套主题色（含黑色主题），深色界面适配

## 技术栈
- 语言：Kotlin（JVM 17）
- IDE：Android Studio
- 构建：Gradle 8.4 + AGP 8.2.0
- 架构：多 Activity + ViewBinding，原生 Android 组件
- 存储：Room（本地 SQLite），Gson 负责 JSON 备份
- 异步：Kotlin Coroutines + Room KTX
- 图片：Coil / Coil-GIF，从 assets 离线加载动作动图
- 兼容性：minSdk 26 / targetSdk 34

## 注意事项
1. 当前为个人学习项目，仅用于学习Android原生开发，不面向商用。
2. 数据默认保存在手机本地，建议经常导出JSON备份，防止卸载丢失数据。
3. App不连接网络服务器，所有训练数据不会自动上传。
