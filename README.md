# BC
> 一款Android原生健身训练记录应用，专为健身爱好者设计，记录力量、有氧训练，提供日历、数据统计、数据备份完整能力。

## 项目简介
BC 是BC独立开发的安卓健身记录工具，目标是做一套轻量、本地优先的健身日志App。
告别纸质笔记，记录每一次训练的重量、组数、次数、RPE、休息时长，支持力量训练与有氧训练双体系，提供日历视图、训练统计图表、JSON导入导出备份。
整个项目使用 Kotlin 原生开发，无后端服务，数据优先保存在本地设备。

## 核心功能
### 力量训练模块
- 训练部位管理：胸、肩、背、腿、手臂、核心，网格首页展示，点击进入对应动作列表
- 动作库管理：每个部位挂载对应训练动作，可后续扩展自定义动作
- 训练记录表单：双颗粒度录入模式
  - 快速模式：简单录入重量、组数、次数
  - 专业模式：补充训练体重、RPE主观疲劳度、组间休息秒数
- 动作历史：每个动作页面可查看该动作过往训练历史，直观看到重量进步
- 组间计时器：训练时一键开启倒计时，辅助组间休息

### 有氧训练模块
独立有氧模块，和力量训练平级
- 内置常见有氧动作：慢跑、快走、跳绳、骑行、游泳、爬楼等
- 记录时长、备注

### 日历模块
- 月历网格视图，标记已经完成训练的日期
- 点击日期，查看当日全部训练记录（力量+有氧）

### 数据统计模块
- 训练频次统计：每月训练次数
- 动作维度统计：同一个动作历史重量变化
- 训练记录汇总，复盘训练进度

### 备份与恢复
- JSON格式导出训练全部记录
- JSON文件导入恢复数据
- 使用SAF存储访问框架，不需要申请存储权限

### 体验优化
- 暗黑模式切换

## 仓库说明
- app：应用主模块代码

- `.gitignore`：忽略编译产物、本地配置文件，不提交缓存与个人配置

## 注意事项
1. 当前为个人学习项目，仅用于学习Android原生开发，不面向商用。
2. 数据默认保存在手机本地，建议经常导出JSON备份，防止卸载丢失数据。
3. App不连接网络服务器，所有训练数据不会自动上传。
